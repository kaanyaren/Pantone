# PantonAK

Colour converter for Pantone C/U/TCX/TPX, hex, RGB, CMYK, Madeira Polyneon/Rayon, and Durak Polysoft/Visco.

**Status:** implemented. 9,149 rows across 8 systems, 52 tests passing, static GitHub Pages build. Live at https://kaanyaren.github.io/Pantone/. See [`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md).

## Design

- Hallmark genre `editorial`, theme `Grid`, macrostructure `Workbench`.
- Archivo for display and body; JetBrains Mono for codes, hex, and numeric data.
- Typographic wordmark in `public/brand/logo.svg`; mark in `public/brand/mark.svg`.
- Favicon, Apple touch icon, web manifest, and social card live in `public/`.

## Local development

Requires Node 22.18 or newer. CI uses Node 24.

```bash
npm install
npm run data    # rebuild public/data/colors.json from data/raw
npm run dev     # local dev server
npm test        # node --test on test/**/*.test.ts
npm run build   # data, typecheck, then Vite build to dist/
```

Preview a production build with `npm run preview`.

## Data

`public/data/colors.json` is generated by `scripts/build-data.ts` from the snapshots in `data/raw/`, using `data/manifest.json` and `data/LICENSES.md`. The generated file is committed, so the site builds without network access.

To refresh:

1. Update the raw snapshots in `data/raw/` and record the change in `data/manifest.json`.
2. Run `npm run data`.
3. Run `npm test` to check dataset invariants.
4. Commit the regenerated `public/data/colors.json` with the source change.

Do not hand-edit `colors.json`. A data rollback is a revert of the generated file.

## Deployment

GitHub Pages, built and deployed by GitHub Actions (`.github/workflows/deploy.yml`) on every push to `main`. Vite uses a relative base, so the site works at `https://<user>.github.io/Pantone/`.

One-time setup:

1. Push the repository to GitHub with `main` as the default branch.
2. Go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Run the workflow, or push to `main`, and check the deployment URL in the Actions run.

`public/.nojekyll` disables Jekyll processing. `public/robots.txt` allows all crawlers.

### Custom domain

Add `public/CNAME` containing the bare domain only after the domain is live and the DNS records point at GitHub Pages. Then set the domain in **Settings → Pages** and enable HTTPS. A relative Vite base works unchanged at the domain root.
