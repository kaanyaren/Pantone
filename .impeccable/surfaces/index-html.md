# Surface Brief — index.html

- **Scope:** Single-page colour conversion workbench (`index.html`)
- **Mode:** Operate

## Direction contract

**THESIS:** PantonAK is an immediate, zero-ceremony colour and thread matching workstation that opens directly into a live 8-system conversion workspace, refusing both marketing-page hero bloat and sterile grey-on-white utility templates.

**OWN-WORLD:** Warm D50 viewing-booth paper (`oklch(97.6% 0.008 80)`), deep slate-carbon top command bar (`oklch(19% 0.015 260)`), warm vermilion rubric accent (`oklch(52% 0.19 30)`), and semantic ΔE00 tolerance tokens (`exact`, `close`, `noticeable`, `loose`), set in Archivo for UI labels and JetBrains Mono (`tabular-nums`, `"zero" 1`) for codes and colour coordinates.

**STORY:** A designer or embroidery digitizer enters or picks a colour in the command bar, inspects the zero-gap Split Swatch Loupe and ΔE00 Perceptual Tolerance Strip on the left inspection rail, filters or scans all eight libraries on the right matrix, and copies any code, hex, RGB, CMYK, or full TSV table in one click.

**FIRST VIEWPORT:** A committed dark top instrument bar housing the brand mark, inline command search (`/`), colour picker, and sample chips; below it, a Split Studio two-pane workspace with the sticky Split Swatch Loupe + ΔE00 Perceptual Ruler on the left (`320px`) and the live 8-system comparison matrix on the right (`minmax(0, 1fr)`), pre-loaded with a live specimen so the tool operates at first glance.

**FORM:** Candidate 4 — Textile Mill Lab-Dip & Shade-Card Approval Workbench (seed key `4b24bce5`), raised by `rw-timetable-slide-rack` (tabular rank discipline), `vernacular-ephemera-boarding-pass-and-gate-board` (segmented readout + live row inspection), and `rw-centre-rail-reference-setting` (1px hairline precision + vermilion rubric signal).

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
